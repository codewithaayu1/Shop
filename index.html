Roz Raat Automatic Report — Setup
Yeh HTML file sirf browser mein khula ho to hi JS chal sakta hai — band phone pe apne aap kuch nahi bhej sakta.
Bina button dabaye roz raat 9-10 baje automatic bhejne ke liye ek free Google Apps Script use karo — neeche steps hai.
Free automatic setup (5 min, ₹0 khaarch):
1. script.google.com pe naya project banao.
2. Firestore REST API se aaj ka data fetch karo (UrlFetchApp.fetch), phir MailApp.sendEmail() se email bhejo — Gmail free hai, isme koi paisa nahi lagta.
3. WhatsApp ke liye callmebot.com ka free API use karo (ek baar apne number se opt-in karna padta hai).
4. Apps Script mein "Triggers" → "Time-driven" → roz raat 9 baje wala trigger laga do. Ye Google ke server pe chalega, tumhara phone/laptop band bhi ho to bhi chalega.
5. Roz Google Sheet mein auto-backup ke liye: usi trigger mein SpreadsheetApp.openById() se apni Sheet kholo aur Firestore se mila data appendRow() se daal do — bilkul free, ek hi script mein WhatsApp + Sheet backup dono ho sakte hain.
Chaho to main tumhare liye ye poora Apps Script code alag se likh sakta hoon — bata do.
